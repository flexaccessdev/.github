# Flex Access Dev

Open-source tunneling and VPN utilities for reaching private networks — no public IP, no open inbound port, no port forwarding needed on the server.

**🌐 [flexaccess.dev](https://flexaccess.dev)** — the full overview: what each tool does, how they compare, and which one you want.

## Projects

- [ezvpn](https://github.com/flexaccessdev/ezvpn) — the easy-setup VPN ([site](https://flexaccess.dev/ezvpn)) · clients: [ezvpn-apple](https://github.com/flexaccessdev/ezvpn-apple), [ezvpn-windows](https://github.com/flexaccessdev/ezvpn-windows)
- [flextunnel](https://github.com/flexaccessdev/flextunnel) — the rootless split tunnel for private TCP services ([site](https://flexaccess.dev/flextunnel)) · clients: [flextunnel-ios](https://github.com/flexaccessdev/flextunnel-ios)

These tools provide access to networks you control — both ends are run by the same trusted party, with token-based client authentication. Never commit credentials, auth tokens, private keys, or connection profiles.
